# Labass — app santé (Vite + React + Framer Motion + Capacitor)

- `npm run dev` : dev local
- Vidéos breathing : `./scripts/download-videos.sh` sur ton PC (mp4 dans `public/videos/`), sinon l'app propose le lien YouTube.
- APK : `npm run apk` (Android Studio/JDK 21 requis) → `android/app/build/outputs/apk/debug/app-debug.apk`
  ou GitHub → Actions → « Build APK » → artifact `labass-apk`.
